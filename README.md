# JLPT N2 - 15 NGÀY LUYỆN ĐỀ CHUYÊN SÂU

Ứng dụng web ôn thi JLPT N2 dạng tương tác trực tiếp chạy bằng HTML/JS/CSS, không cần cài đặt server hay database phức tạp.

## 🚀 Cách Mở Ứng Dụng
1. Nhấp đúp chuột vào file `run.bat` (hoặc mở trực tiếp file `index.html` bằng trình duyệt Chrome, Edge, Cốc Cốc...).
2. Bắt đầu làm bài ngay lập tức!

## 🎯 Tính Năng Nổi Bật
- **Lộ trình 15 Ngày**: Đầy đủ 15 buổi theo đúng cấu trúc thư mục tài liệu.
- **Bỏ qua phần Nghe hiểu (Choukai)** theo đúng yêu cầu: Tập trung tối đa vào **Từ vựng, Chữ Hán, Ngữ pháp Dấu sao và Đọc hiểu**.
- **Chế độ Luyện Tập (Practice Mode)**: Làm câu nào xem giải thích chi tiết, dịch nghĩa tiếng Việt và mẹo ngữ pháp ngay lập tức.
- **Chế độ Thi Thử (Exam Mode)**: Bấm giờ đếm ngược 105 phút chuẩn kỳ thi thật N2.
- **Dạng bài tập tương tác cao**:
  - Trắc nghiệm 4 đáp án (hỗ trợ phím tắt 1, 2, 3, 4).
  - Ghép câu Dấu sao $\star$ (Mondai 8): Bấm chọn các mảnh ghép theo thứ tự, tự nhận diện vị trí dấu $\star$.
  - Đọc hiểu: Bài đọc hiển thị song song với câu hỏi.
- **Sổ tay câu sai & Tự động lưu tiến độ**: Lưu lịch sử làm bài, điểm số và chuỗi ngày học trên LocalStorage của trình duyệt.
